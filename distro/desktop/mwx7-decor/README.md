# mwx7-decor

MWX 7 window frames for Wayfire 0.9: Debian's decoration plugin (MIT, © Iliya Bozhinov and Wayfire contributors,
see `LICENSE.wayfire`) with MWX 7's look:
- translucent glass frame (Wayfire's blur shows through), a white gloss over the upper title bar and a bright top edge
- left-aligned semibold title with a white caption glow, greyer when the window is not focused
- glossy traffic lights (green maximize, yellow minimize, red close) that turn grey on unfocused windows and show
  their symbol under the pointer

Built inside the ISO's chroot against `wayfire-dev` by `distro/desktop/setup.sh`.
